# Agent handoff

This repository is a single-module Java 21 Spring Boot 4.1.2 demonstration.
Keep code and commits in English; keep UI, demo content, errors, and README in Romanian.
Run `./mvnw -q test` after edits and `./mvnw clean verify` for the final gate.
Do not alter oracle values in `DemoOracleTest`; adjust demo curricula if a seed correction is needed.
Maintain one committed milestone at a time. Inspect `.agents/progress.json` for the current checkpoint.
